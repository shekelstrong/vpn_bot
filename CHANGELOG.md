# Changelog

Все изменения в проекте Nemo VPN Bot.

## [1.0.0] - 2024-01-01

### Добавлено
- ✅ Полная интеграция с Marzban API для управления пользователями
- ✅ Поддержка протокола VLESS Reality для обхода блокировок
- ✅ Система бесплатного 24-часового триала (1GB трафика)
- ✅ Платежная интеграция с CryptoBot (USDT, TON, Bitcoin)
- ✅ Платежная интеграция с Platega (банковские карты РФ)
- ✅ 3-уровневая реферальная программа (15%, 10%, 5%)
- ✅ Автоматические уведомления об истечении подписки (9 интервалов)
- ✅ Админ-панель со статистикой и управлением пользователями
- ✅ Система подарочных подписок для администраторов
- ✅ Рассылка сообщений всем пользователям
- ✅ Интеграция с Hiddify Next (инструкции по настройке)
- ✅ Асинхронная архитектура на aiogram 3.x
- ✅ PostgreSQL база данных с SQLAlchemy 2.0
- ✅ Docker и Docker Compose для деплоя
- ✅ Логирование через loguru с ротацией файлов
- ✅ Graceful shutdown для корректной остановки

### Технические детали
- Python 3.10+
- aiogram 3.x
- SQLAlchemy 2.0 (Async)
- httpx (асинхронный HTTP клиент)
- APScheduler для фоновых задач
- Pydantic для валидации настроек

### Структура проекта
- `bot.py` — точка входа
- `config.py` — конфигурация через Pydantic Settings
- `database/` — модели и движок БД
- `handlers/` — обработчики команд (start, profile, buy, trial, help, admin)
- `keyboards/` — inline и reply клавиатуры
- `services/` — внешние API (Marzban, CryptoBot, Platega)
- `utils/` — планировщик и FSM состояния

### Известные ограничения
- Вебхуки для Platega требуют дополнительной настройки на сервере
- Автоматическое удаление пользователей из Marzban отключено (можно включить в scheduler.py)
- Вывод реферальных средств реализован вручную через админ-панель
